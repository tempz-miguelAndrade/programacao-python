# Lista de Exercícios – If Ternário (Python)

## Objetivo

Praticar estruturas de decisão em Python usando **if ternário**.

## Exercícios

1. **Exercício 01 – Verificar par ou ímpar**
   Leia um número inteiro e informe "PAR" ou "ÍMPAR" usando operação ternária.

2. **Exercício 02 – Número positivo, negativo ou zero**
   Leia um número e determine se ele é positivo, negativo ou zero, utilizando ternário aninhado.

3. **Exercício 03 – Maioridade**
   Pergunte a idade de uma pessoa e exiba "Maior de idade" ou "Menor de idade" com if ternário.

4. **Exercício 04 – Maior número**
   Leia dois números e mostre qual é o maior usando ternário.
   Se forem iguais, exiba "Números iguais".

5. **Exercício 05 – Aprovação escolar**
   Leia a média final de um aluno e imprima:

   * "Reprovado" se média < 5
   * "Recuperação" se estiver entre 5 e 6.9
   * "Aprovado" se média ≥ 7
     Use ternários aninhados.
