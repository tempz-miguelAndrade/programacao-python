   # Lista de Exercícios – If / Else (Python)

   ## Objetivo  
   Praticar estruturas de decisão em Python usando `if`, `elif` e `else`.

   ## Exercícios  

   1. **Exercício 01 – Verificar par ou ímpar**  
      Leia um número inteiro e imprima `"PAR"` se ele for par, ou `"ÍMPAR"` se for ímpar.

   2. **Exercício 02 – Número positivo, negativo ou zero**  
      Leia um número e informe se ele é positivo, negativo ou igual a zero.

   3. **Exercício 03 – Faixa etária**  
      Leia a idade de uma pessoa e imprima:
      - `"Criança"` se for menor que 13  
      - `"Adolescente"` se for de 13 a 19  
      - `"Adulto"` se for de 20 a 64  
      - `"Idoso"` se for 65 ou mais

   4. **Exercício 04 – Maioridade**  
      Pergunte a idade de uma pessoa e diga se ela é maior de idade (18 anos ou mais) ou menor de idade.

   5. **Exercício 05 – Classificação de nota**  
      Leia uma nota de 0 a 10 e imprima:
      - `"Muito ruim"` para notas abaixo de 4  
      - `"Ruim"` entre 4 e 5.9  
      - `"Bom"` entre 6 e 7.9  
      - `"Ótimo"` entre 8 e 10

   6. **Exercício 06 – Senha correta**  
      Peça ao usuário que digite uma senha.  
      Se a senha for `"1234"`, escreva `"ACESSO PERMITIDO"`.  
      Caso contrário, `"ACESSO NEGADO"`.

   7. **Exercício 07 – Maior número entre dois**  
      Leia dois números e informe qual deles é o maior.  
      Se forem iguais, informe `"Números iguais"`.

   8. **Exercício 08 – Cálculo de multa por velocidade**  
      Leia a velocidade de um carro.  
      Se for maior que 80 km/h, mostre:  
      `"Você foi multado! Valor da multa: R$ X"`  
      (R$ 7 por km acima do limite).  
      Caso contrário, imprima `"Dentro do limite"`.

   9. **Exercício 09 – Aprovação escolar**  
      Leia a média final de um aluno:  
      - Se média < 5 → `"Reprovado"`  
      - Se média entre 5 e 6.9 → `"Recuperação"`  
      - Se média ≥ 7 → `"Aprovado"`

   10. **Exercício 10 – Categoria de trabalhador**  
      Leia a idade e exiba:  
      - `"Jovem aprendiz"` se idade < 18  
      - `"Trabalhador adulto"` se idade entre 18 e 59  
      - `"Aposentado"` se idade ≥ 60
