# Operadores Aritméticos em Python

Este diretório contém uma introdução aos **operadores aritméticos**, usados para realizar cálculos básicos em Python.

Eles são essenciais para qualquer programa que trabalhe com números.

---

## 🔢 Operadores Aritméticos

### **Soma com `+` Adição**
a = 5 + 3  # 8


### **Soma com `-` Subitração**
a = 5 - 3  # 2


### **Soma com `*` Multiplicação**
a = 7 * 6  # 42


### **Soma com `/` Divisão**
a = 10 / 4  # 2.5


### **Soma com `//` Arredondação da divisão**
**Arredonda a divisão**
a = 10 / 4  # 2


### **Soma com `%` Resto da divisão**
a = 10 % 4  # 2


### **Soma com `**` Exponencial**
a = 2 ** 3  # 8
